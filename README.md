# 多波段 Sentinel-2 洪水淹没范围提取（Lightweight U-Net）

本仓库对应论文《多波段Sentinel-2影像的轻量化U-Net洪水淹没范围提取》，包含实验代码、结果文件与图件，便于复现论文中的全部指标。

## 主要结果

在 USGS 洪水子集上按**场景**进行 5 折交叉验证（33 个场景、9124 个 256×256 样本块）：

| 方法 | IoU/%（均值±标准差） | 参数量/10⁶ |
|---|---|---|
| 标准 U-Net | 86.46 ± 10.69 | 7.77 |
| U-Net++（ResNet-34） | 84.96 ± 11.21 | 22.54 |
| DeepLabV3+（ResNet-50） | 86.80 ± 10.23 | 40.37 |
| **本文（16 波段）** | **87.66 ± 9.60** | **1.07** |
| 本文 + NDWI（17 通道） | 88.41 ± 9.98 | 1.07 |
| 仅前 4 波段 | 79.20 ± 11.97 | 1.07 |

主模型 F1 = 93.20%，总体精度 = 99.13%，精确率 = 98.56%，召回率 = 88.79%。

## 方法要点

- **输入**：16 通道（Sentinel-2 的 13 个光谱波段 + 3 个质量波段），可选增加 NDWI 通道至 17 通道
- **网络**：U-Net 骨架，编码/解码阶段的标准 3×3 卷积替换为深度可分离卷积，参数量 1.07×10⁶
- **损失**：BCE + 0.5 × Dice，仅在有效像元上计算（云与无效值被忽略）
- **划分**：以场景为单位 5 折，训练集与验证集在场景层面完全不重叠

## 复现

```bash
# 1. 准备数据（FloodsNet 的 USGS 子集，含 S2、CLASS、NDWI 栅格）
#    见 https://zenodo.org/records/8298840
# 2. 切块（256×256，步长 128）
python code/build_chips2.py          # 16 通道
python code/build_chips3.py          # 17 通道（附 NDWI）
# 3. 训练（5 折）
python code/train_usgs.py --epochs 60 --folds 0 --tag base
# 4. 评估
python code/eval_full.py base
# 5. 汇总
python code/aggregate.py
```
