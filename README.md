# 多波段 Sentinel-2 影像的轻量化 U-Net 地表水体提取与鄱阳湖应用

本仓库对应论文《多波段Sentinel-2影像的轻量化U-Net地表水体提取与鄱阳湖应用》（投《上海师范大学学报（自然科学版）》"AI+"专题），包含训练/评估代码、5 折划分与逐折结果、论文图件，便于复现论文中的全部指标。

## 主要结果

在 FloodsNet 的 USGS 子集上按**场景**进行 5 折交叉验证（33 个场景、9124个256×256样本块，块间重叠 50%）：

| 方法 | IoU/%（均值±标准差） | 参数量/10⁶ |
|---|---|---|
| MNDWI>0（物理阈值） | 60.78 ± 23.87 | — |
| 仅前 4 波段（B1—B4，无近红外；消融对照） | 79.20 ± 11.97 | 1.07 |
| NDWI>0（物理阈值） | 80.44 ± 18.54 | — |
| U-Net++ | 84.96 ± 11.21 | 26.12 |
| 标准 U-Net | 86.46 ± 10.69 | 7.78 |
| DeepLabV3+ | 86.80 ± 10.23 | 26.72 |
| SegFormer（MiT-B0） | 86.99 ± 9.61 | 5.56 |
| **本文（13 光谱波段，16 通道输入）** | **87.66 ± 9.60** | **1.07** |
| RGB + 近红外（B2/B3/B4/B8；消融） | 87.86 ± 9.51 | 1.07 |
| 本文 + NDWI（17 通道；消融） | 88.41 ± 9.98 | 1.07 |

表中按 IoU 由低到高排列；带"消融"的行为输入配置实验，用于说明近红外与 NDWI 通道的作用，非独立对比方法。RGB+近红外的 IoU 虽略高于 13 波段，但二者在 33 个场景上的配对 Wilcoxon 检验无显著差异（p = 0.54），差异小于折间标准差；论文因此保留 13 波段输入，并以 4 波段结果作为波段裁剪的依据。

以上为本文 13 光谱波段主模型的 5 折平均指标：F1 = 93.20%，总体精度 = 99.13%，精确率 = 98.56%，召回率 = 88.79%。

外部验证：不经微调用于 WorldFloods 中 5 个时相一致的事件，平均 IoU 91.00%；同样不经微调用于鄱阳湖 2019—2024 年 6 期汛期影像，水体比例 21.26%~47.52%。

## 目录结构

```
code/        训练、评估、切块、统计与制图脚本
results/     5 折交叉验证的逐折结果（npy/done/json）与模型开销（cost.json）
figs/        论文图件（技术路线、网络结构、收敛曲线、逐场景分布、对比图、频率图、SHAP）
splits.json  33 个场景的 5 折划分（按场景，seed=42；第 k 折列出验证场景）
infer_demo.py 单景推理示例：输入 16 通道 TIF，输出二值水体掩膜
```

## 方法要点

- **输入**：16 通道（Sentinel-2 的 13 个光谱波段 + QA10/QA20/QA60 三个质量通道），该子集中三个质量通道恒为 0；扩展实验增加 NDWI 至 17 通道
- **网络**：U-Net 骨架，编码/解码阶段的标准 3×3 卷积替换为深度可分离卷积，参数量 1.07×10⁶、6.74 GFLOPs
- **损失**：BCE + 0.5 × Dice，仅在有效像元上计算（云与无效值被忽略）
- **划分**：以场景为单位 5 折，训练集与验证集在场景层面完全不重叠

## 复现

```bash
# 推荐环境：Python 3.10+、PyTorch 2.5.1、CUDA 12.x
pip install -r requirements.txt

# 1. 准备数据（FloodsNet 的 USGS 子集，含 S2、CLASS、NDWI 栅格）
#    https://doi.org/10.5281/zenodo.8298840
# 2. 切块（256×256，步长 128）
python code/build_chips2.py          # 16 通道
python code/build_chips3.py          # 17 通道（附 NDWI）
# 3. 训练（逐折）
python code/train_usgs.py --epochs 60 --folds 0 --tag base
# 4. 评估与汇总
python code/eval_full.py base
python code/aggregate.py
```

数据集解压后保持 FloodsNet USGS 子集的原始目录结构，并以环境变量 `F2_ROOT` 指定其根目录（脚本默认 `~/F2`）。

逐折 IoU 以 `results/f*_*.done` 中的 `best` 字段为准；`splits.json` 与训练脚本使用同一随机种子（42）生成，可直接对齐。
